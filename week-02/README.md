
# My Personal Developer Portfolio

## About the Project

This is my personal developer portfolio, built as part of the Averon Academy Week 2 assignment.

The website introduces me, shares my interests and developer goals, lists my current skills, and provides contact information.

## Technologies Used

- HTML5
- CSS3
- Git and GitHub

## Website Sections

- Home
- About Me
- Skills
- Developer Goals
- Contact

## What I Learned

During this project, I practiced:

- Structuring a webpage with HTML
- Using semantic HTML elements
- Styling a webpage with CSS
- Creating navigation links
- Learning the basics of responsive design
- Organizing project files

## How to View the Project

Open `index.html` in a web browser to view the portfolio.
